# MUSE by ACAS Tools: Android beta

Free beta of MUSE for Android phones and tablets. Everything is unlocked.

## Install

1. On your Android device, open the **[latest release](../../releases/latest)** and tap the `.apk` file to download it.
2. Open the downloaded file. If Android asks, allow your browser or Files app to **install unknown apps**.
3. Tap **Install**, then open **MUSE**.

To update, install a newer `.apk` from this page over the old one. Your settings are kept.
